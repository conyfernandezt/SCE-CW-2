# HyperBasket Quick Fulfiller Student Package

This package contains the complete casework and all released data required for Tasks 1 through 6. The included order history is the forecasting year and covers 365 consecutive days from September 7, 2026 through September 6, 2027. The evaluation tool uses a separate withheld year. Storage and staging modules include complete exterior dimensions, position grids, usable volumes, costs, and energy requirements.
